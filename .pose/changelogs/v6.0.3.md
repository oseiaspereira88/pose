# POSE v6.0.3

## Changed

- Prepare POSE 6.0.3 with aligned public version metadata and an authenticated upgrade path from 6.0.2, pinned by the SHA-256 of its published `checksums.txt`. The release introduces no contract, schema or capability. (pose-v6-0-3-release-readiness)

## Fixed

- A closed scope whose newest approval no longer validates, typically against an evidence rule introduced after it, keeps the older approval it was closed with again. 6.0.2 voided it, so a scope approved twice and never rejected read as unreviewed and `pose check --strict` failed. A newer rejection or request for changes still voids any older approval. (retained-review-survives-an-invalid-newer-approval)
