# POSE v1.5.0

## Added

- Added `--target <dir>` flag support to `pose extension install`, expanded multi-word command dispatch checks in scaffold parity tests, and added end-to-end stack detection fixtures for Poetry, Pipenv, and .NET. (pose-cli-ergonomics-and-stack-expansion)
- Added universal, first-class `-h` and `--help` flag support across all POSE CLI commands and subcommands, hierarchical `pose help <command> [subcommand]` resolution, and rich bilingual documentation (synopsis, flags, examples) with standard POSIX exit code 0. (pose-cli-universal-help-and-subcommand-introspection)
- Added native `pose contribute` CLI command suite (`enable`, `disable`, `status`, `stage`, `list`) and governed Contributor Mode protocol, allowing developers to opt in to automatic local staging of sanitized POSE feedback and engine improvements with strict privacy guarantees and developer-adjudicated submissions. (pose-contributor-mode-protocol)
- Added 4 new curated domain rule extensions with full bilingual parity (`pose-rule-frontend-vue`, `pose-rule-frontend-svelte`, `pose-rule-infra-docker`, and `pose-rule-cicd-github-actions`), expanded dependency-aware frontend resolution in `rule_extension_resolver`, and consolidated component manifest discovery across all supported language markers. (pose-engine-discovery-consolidation-and-onboarding)
- Added the `pose spec-format` CLI command suite with `migrate <slug>|--all` and `status` subcommands, allowing automated migration of legacy specifications to modern date-prefixed formats (`YYYY-MM-DD-<slug>/spec.md` or `YYYY-MM-DD-<slug>.md`) while strictly preserving directory envelopes for specs with companion artifacts (`amendments.jsonl`). (pose-spec-format-migration-command)
- Added hybrid and resilient spec resolution (supporting date-prefixed folders `YYYY-MM-DD-<slug>/spec.md` and flat files `YYYY-MM-DD-<slug>.md` with 100% backward compatibility), `pose new-spec` `--dated` and `--flat` scaffolding options, the `pose specs` discovery CLI command with `--recent`, `--status`, `--since`, and `--json`, and expanded the `pose_list_specs` MCP tool with recent and sort options. (pose-specs-ergonomics-and-discovery)
- Added 6 new curated domain rule extensions with full bilingual parity (English and Portuguese): `pose-rule-backend-python`, `pose-rule-backend-rust`, `pose-rule-backend-java`, `pose-rule-backend-dotnet`, `pose-rule-serverless-cloudflare`, and `pose-rule-infra-terraform`, and wired automatic stack resolution in the native engine. (pose-stack-rule-extensions-expansion)

## Changed

- Documented the mandatory `POSE-Spec: <slug>` Git commit trailer requirement across `AGENTS.md`, `POSE.md`, task workflows (`feature`, `bugfix`, `refactor`), AI agent skills (`pose-feature`, `pose-bugfix`, `pose-spec-closeout`), and distributed engine scaffolds in English and Portuguese (`pt-BR`). (pose-spec-trailer-workflow-documentation)

## Fixed

- Unify Git changeset attribution across graph generation, surface verification, and spec closeout, eliminating false `action-mismatch` failures when closing specs with live Git commit trailers. Enhance delivery assurance blocker reporting with exact artifact paths, declared actions, and actionable remediation guidance. (pose-closeout-delivery-assurance-convergence)
- Hardened engine stability by adding Git commit trailer recognition to `pose doctor`, eliminating spurious `resolvability` errors in `pose artifact-check` for `none`-action claims, normalizing `.gitignore` trailing slash lookups across module discovery walkers, and replacing test self-execution with stable binaries. (pose-engine-stability-and-diagnostics-convergence)
