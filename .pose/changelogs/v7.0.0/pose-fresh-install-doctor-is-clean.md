A fresh install now opens `pose doctor` with no warning and, once committed, `pose state --attention` with complete coverage. Doctor gains a `next` level for recommended steps that are not problems — the pre-commit hook and naming action roles — listed and counted apart (`next_steps` in the JSON, `doctor_schema_version` 2) and never changing the exit code. Milestone and roadmap profiles count in the class-producers check only once the project has a roadmap; evidence-class coverage reads only the required checks of the shipped stacks some module uses, and every shipped test and build check now declares its evidence class. Attention lists the not-yet-projected sources a project does not have (docs manifest, release, capability assessment, legacy findings) as `not_used` instead of calling coverage incomplete; a source the project does use still does.
