# POSE v1.0.0

## Added

- POSE now measures local CLI and MCP tool usage automatically and exposes privacy-bounded aggregates through `pose usage` and `pose_usage`, including semantic outcomes, finding lifecycle and latency without agent-maintained counters or individual tracking. (pose-usage-metrics)

## Changed

- `pose dora-metrics` now reports the current five production delivery metrics, replacing the former Reliability proxy with deployment rework rate and limiting recovery time to resolved incidents explicitly caused by a deployment. New deployment and incident events require rework/environment classification; schema-v1 JSONL remains readable without guessed values. (pose-dora-five-metrics-v2)

## Fixed

- Managed manual refreshes once again preserve each installed repository's own project name instead of replacing it with the POSE source repository name. (pose-managed-doc-project-identity-regression)
