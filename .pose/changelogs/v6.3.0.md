# POSE v6.3.0

## Added

- Retain an automated clean-container activation measurement and a real blocked-then-resolved terminal recording; the reported command-path timing excludes human reading and development. (pose-clean-activation-evidence)
- Repair runtime evidence for bounded same-repository Dependabot action-pin PRs using trusted scripts, a non-forced manifest-only commit and explicit CI dispatch. (pose-dependabot-runtime-repair)
- Let a project declare the file that holds its own release version with `version_source` in `.pose/policy/release.json`, so `pose release plan`, `prepare` and `check` work outside the engine repository. A project with no declared source outside the engine repository is now refused with a message naming the field instead of being compared with the engine's version; policies that do not set it digest as before. (pose-release-version-source)

## Changed

- Fail deterministic gates on omitted local checks, unpaired release steps and missing published assets. Seal exact root gitleaks configuration bytes without generalizing the review boundary. (pose-ci-release-completeness)
- Write the delivery-integrity index in schema 2: validation runs and result sets are stored once, repeated edges are written once and `changes` edges are derived from the change sets. On this repository the index shrinks from 10.9 MB to 4.6 MB for the same inputs, with the same provenance digest, claims, change sets and findings, and it now grows with deliveries rather than with deliveries times results. Gates and MCP tools read the same graph as before. An earlier engine refuses a schema 2 index as invalid until `pose index` rewrites it; this engine still reads schema 1. (pose-delivery-integrity-index-compaction)

## Fixed

- Keep coloured table alignment and UTF-8 wrapping consistent across profiles, fully localize token errors, and preserve quiet output and structured findings. (pose-cli-profile-parity)
- Show the absolute extension destination in the installation plan and reject malformed or absent targets before package lookup or writes. (pose-extension-target-preview)
