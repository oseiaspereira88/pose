The brief a delegated reviewer receives (`review-brief/4`) now states the rules the attestation preflight applies to a typed conclusion, so a draft that follows it is not refused for its shape: a passed judgment criterion carries a rationale, its evidence is a ref the bundle sealed, a finding criterion names a finding of the draft, structural facts are answered as mappings. `review-brief/3` still renders as before for the runs briefed with it. The Claude reviewer profile may now run read-only commands (Git reads, `go test`, `go vet`, the read-only checks), so it can reproduce the tests instead of citing file and line.
