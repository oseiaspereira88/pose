# POSE v1.2.1

## Fixed

- `pose install`/`pose update --force` no longer seeds a project's `.pose/policy/delivery.json`/`artifacts.json` with roots that describe pose-mcp's own source tree instead of the target project's — the embedded template now ships an explicit, disabled placeholder until the project configures its own roots. `pose doctor` also gained two new checks that warn when an already-seeded policy file's roots do not resolve on disk, so instances installed before this fix can find and repair the contamination. Separately, the `pose_validate_approve` MCP tool's error message now explains that it is unavailable over the stdio transport by design (no Execution Identity header channel exists there) and points at `pose review attest`/ `pose review auto-attest` as the supported local alternative. (pose-scaffold-self-referential-policy-fix)
