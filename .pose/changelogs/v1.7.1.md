# POSE v1.7.1

## Added

- Integrated end-to-end Contributor Mode guidance across AI agent skills (`pose-bugfix`, `pose-review`, `pose-spec-closeout`, `pose-recurrence-escalation`, `pose-feature`) and core workflows in both English and Portuguese. Added non-intrusive contextual CLI hints when check/lint/close failures or doctor diagnostics occur under active contributor mode, automatically staging feedback without leaking proprietary code. (pose-contributor-mode-workflow-and-cli-hints)

## Fixed

- Resolved issue #33: Changed `pose new-spec` default layout to modern date-prefixed flat file `.pose/specs/YYYY-MM-DD-<slug>.md` so that newly scaffolded specifications immediately conform (`pose spec-format status` reports `conforming: true`). Added `--folder` flag for creating date-prefixed folder envelope when specs include amendments, and enhanced `pose spec-format migrate` to convert dated folders to flat files while preserving folders with amendments. (pose-new-spec-default-flat-format)
- Resolved issue #32: Corrected the policy reference link in the `pose-release-closeout` skill to point to canonical `.pose/policy/changelog.json` in English and Portuguese, ensuring clean out-of-the-box `pose skills-check --strict` execution on freshly initialized schema-v1 instances. (pose-release-closeout-skill-policy-link)
- Resolved issue #31: Enhanced review plan component discovery to synthesize modules across metadata, state, and top-level directory discovery without requiring a pre-existing repo-map. Expanded review bundle path classification to recognize ADR conventions (`docs/decisions/`), roadmaps (`.pose/roadmaps/`), and governance manifests. Fixed `pose artifact-check` to honor recorded change-set reports from history logs. (pose-review-bundle-component-discovery-and-governance-paths)
