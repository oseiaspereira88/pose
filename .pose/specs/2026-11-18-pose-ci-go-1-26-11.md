# Spec: Update the workflow Go security baseline to 1.26.11

## 1. Intent

### Goal

Resolve the standard-library finding GO-2026-6859 by using Go 1.26.11
across the POSE workflows.

### Business value

The govulncheck job failed on both fbae636a (44318796041) and f7b2fcc7
(44358546514) with Go 1.26.10. The Go vulnerability database identifies
1.26.11 as the first fixed patch in the 1.26 release line.

### Constraints

Preserve the workflow action pins, scanner, test commands and gates.
Preserve the modules' minimum Go versions.

## 2. Requirements

- R1: Every workflow currently pinning Go 1.26.10 shall pin Go 1.26.11.
- R2: The existing govulncheck command shall pass for pose-mcp and mcp-enforce on Go 1.26.11.
